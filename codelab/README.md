# Codelab: Gemini Nano con ML Kit

Esta carpeta contiene el sitio estático del codelab. La experiencia usa una estructura de pasos, barra de progreso, navegación lateral, objetivos y requisitos, hitos persistentes y controles Anterior/Siguiente; está inspirada en el formato de los codelabs sin usar marcas ni recursos de Google Codelabs.

GitHub Pages publica `index.html` mediante el flujo de trabajo `deploy-codelab.yml` cuando hay cambios en `codelab/` sobre la rama `master`.

Para previsualizarlo localmente, abre `codelab/index.html` en un navegador. No necesita compilación ni dependencias externas.
