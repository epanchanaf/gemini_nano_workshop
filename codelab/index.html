Crea una app con Gemini Nano y ML Kit

Integra tareas generativas y dictado local en una app Android con Kotlin, Jetpack Compose, Hilt y las APIs GenAI de ML Kit.

KotlinJetpack ComposeMVVMMADML Kit GenAIGemini Nano

Qué aprenderás

  • Configurar ML Kit GenAI y sus clientes.
  • Entender MVVM, flujo unidireccional de datos y las capas del proyecto.
  • Gestionar disponibilidad y descarga.
  • Mostrar respuestas parciales en Compose.
  • Enviar imagen y texto al chat y transcribir voz.

Qué necesitas

  • Android Studio y JDK 17.
  • Teléfono Android 14+ compatible con AI Core.
  • Conectividad para la primera descarga y permiso de micrófono para dictado.
  • Conocimientos básicos de Compose y corrutinas.
ComenzarDuración estimada: 1 hora y 50 minutos
2.

Configura el proyecto

Abre el repositorio en Android Studio, espera la sincronización y elige un teléfono compatible. El módulo ejecutable es app.

android {
    namespace = "com.sdkecuador.gemininano"
    compileSdk { version = release(37) { minorApiLevel = 1 } }
    defaultConfig { minSdk = 34; targetSdk = 36 }
}

Genera un APK de depuración desde la raíz:

./gradlew assembleDebug
Importante

El proyecto compila aunque AI Core no esté disponible. La app debe comprobar la disponibilidad antes de inferir.

3.

Entiende la arquitectura

La app sigue MVVM (Model-View-ViewModel) y flujo unidireccional de datos. Compose dibuja la interfaz a partir de un estado inmutable; el ViewModel transforma acciones en cambios de estado y el repositorio habla con ML Kit, Room o el sistema. No hay capa domain ni casos de uso separados: para esta demo, la lógica de cada capacidad permanece acotada en su repositorio.

MAD: Modern Android Development

El proyecto aplica prácticas de MAD: Kotlin, Jetpack Compose, ViewModel, Hilt, Navigation Compose, Room, Coroutines y Flow. No es una dependencia llamada “MAD Skills”; es el conjunto de herramientas y patrones modernos de Android que organiza este taller.

Añade ML Kit GenAI

Declara las APIs de cada capacidad en app/build.gradle.kts:

implementation("com.google.mlkit:genai-summarization:1.0.0-beta1")
implementation("com.google.mlkit:genai-image-description:1.0.0-beta1")
implementation("com.google.mlkit:genai-rewriting:1.0.0-beta1")
implementation("com.google.mlkit:genai-proofreading:1.0.0-beta1")
implementation("com.google.mlkit:genai-prompt:1.0.0-beta4")
implementation("com.google.mlkit:genai-speech-recognition:1.0.0-alpha1")

Aísla los clientes del SDK en una fábrica para que los repositorios sean testeables:

interface GenAiClientFactory {
    fun createGenerativeModel(): GenerativeModel
    fun createSummarizer(): Summarizer
    fun createProofreader(): Proofreader
    fun createRewriter(style: RewriteStyle): Rewriter
    fun createImageDescriber(): ImageDescriptionClient
    fun createSpeechRecognizer(options: SpeechRecognizerOptions): SpeechRecognizer
}

ImageDescriptionClient es el adaptador pequeño del proyecto sobre ImageDescriber; facilita las pruebas y encapsula las llamadas asíncronas del SDK.

@Module
@InstallIn(SingletonComponent::class)
abstract class GenAiModule {
    @Binds
    abstract fun bindGenAiClientFactory(factory: MlKitGenAiClientFactory): GenAiClientFactory
}

5.

Gestiona disponibilidad y descarga

Una función no siempre está lista. Traduce el estado del SDK a un modelo propio y emite una secuencia uniforme para la UI.

sealed interface AiOperationState<out T> {
    data object Preparing : AiOperationState<Nothing>
    data class Downloading(val progress: ModelDownloadProgress) : AiOperationState<Nothing>
    data class Generating<T>(val partialResult: T? = null) : AiOperationState<T>
    data class Success<T>(val result: T) : AiOperationState<T>
    data class Failure(val error: AiException) : AiOperationState<Nothing>
}
internal suspend fun prepareModel(status: suspend () -> AiCoreFeatureStatus, download: suspend () -> Unit) {
    when (status()) {
        AiCoreFeatureStatus.DOWNLOADABLE -> { download(); requireAvailable(status()) }
        AiCoreFeatureStatus.AVAILABLE -> Unit
        else -> throw AiException.ModelUnavailable(...)
    }
}
No continúes aún

DOWNLOADABLE no equivale a listo: espera la descarga y vuelve a comprobar el estado.

6.

Crea el resumen

El repositorio posee el cliente, valida la entrada, prepara el modelo y emite estados que el ViewModel adapta a la interfaz. La pantalla ofrece Cargar ejemplo para probar la función sin buscar un artículo.

Idioma del resumen

Esta API de resumen está configurada para inglés; usa artículos en inglés, incluido el ejemplo de la app. ML Kit no ofrece resumen en español mediante esta API.

fun summarizeText(text: String): Flow<AiOperationState<String>> = aiOperation(
    validate = { validateTextInput(text, minimumCharacters = 400, maximumEstimatedTokens = 4_000) },
    prepare = ::prepare
) { onToken ->
    summarizer.runInference(SummarizationRequest.builder(text).build(), onToken).await().summary
}
Buenas prácticas

Cierra el repositorio en onCleared(); las instancias de ML Kit usan recursos que deben liberarse junto con el ViewModel.

7.

Implementa el chat con texto e imágenes

Prompt API permite instrucciones personalizadas. El chat conserva el streaming para texto; cuando se adjunta una imagen construye una solicitud multimodal con ImagePart y TextPart. Combina el prompt y el historial antes de validar el conteo real de tokens.

private suspend fun validatePromptTokens(request: GenerateContentRequest) {
    val inputTokens = model.countTokens(request).totalTokens
    val allowed = (model.getTokenLimit() - MAX_CHAT_OUTPUT_TOKENS).coerceAtLeast(0)
    if (inputTokens > allowed) throw AiException.InvalidInput(InputProblem.TEXT_TOO_LONG)
}

fun streamResponse(prompt: String, history: List<ChatHistoryMessage>, image: Bitmap?): Flow<String> = flow {
    val activeImage = image ?: history.lastOrNull { it.isFromUser && it.image != null }?.image
    val message = (prompt.ifBlank { DEFAULT_IMAGE_PROMPT })
        .withHistory(history, activeImage != null && image == null)
    val builder = if (activeImage == null) {
        GenerateContentRequest.Builder(TextPart(message))
    } else {
        GenerateContentRequest.Builder(ImagePart(activeImage), TextPart(message))
    }
    val request = builder.apply { maxOutputTokens = 256 }.build()
    validatePromptTokens(request)
    if (activeImage == null) {
        emitAll(model.generateContentStream(request).map { it.candidates.firstOrNull()?.text.orEmpty() })
    } else {
        emit(model.generateContent(request).candidates.firstOrNull()?.text.orEmpty())
    }
}

En la interfaz, agrega un selector de imágenes y una vista previa; permite enviar una imagen sin texto usando DEFAULT_IMAGE_PROMPT. El ViewModel mantiene la imagen adjunta para las preguntas posteriores. Para texto, crea una burbuja vacía al recibir Generating y añade los fragmentos; para imagen, muestra la respuesta completa. Valida el tamaño del bitmap y cierra el modelo al terminar.

La pantalla independiente de descripción no usa un prompt: solicita una descripción breve a la API especializada. Esta API ofrece actualmente resultados en inglés; para preguntas personalizadas sobre la imagen usa el chat multimodal del paso anterior. En el repositorio, imageDescriber es el adaptador suspendible ImageDescriptionClient.

val result = imageDescriber.runInference(
    ImageDescriptionRequest.builder(bitmap).build()
)
val description = result.description

Para el dictado local, usa la API Speech Recognition. Declara RECORD_AUDIO en el manifiesto, solicita el permiso en tiempo de ejecución y configura el idioma. El modo Basic utiliza reconocimiento tradicional del dispositivo, no Gemini Nano; el modo Advanced tiene disponibilidad más limitada.

val recognizer = factory.createSpeechRecognizer(speechRecognizerOptions {
    locale = Locale.forLanguageTag("es-ES")
    preferredMode = SpeechRecognizerOptions.Mode.MODE_BASIC
})
val request = speechRecognizerRequest { audioSource = AudioSource.fromMic() }
recognizer.startRecognition(request).collect { response ->
    // Muestra PartialTextResponse y FinalTextResponse en la UI.
}
